## 📖 About

🔹 **RimWorld — MinifyEverything** is a powerful tool built to help you pack and move any building or structure in RimWorld — no more rebuilding furniture and equipment from scratch. With MinifyEverything, every table, power generator, and medical bed can be uninstalled and relocated without material loss.

🔸 Whether you're a seasoned professional or just getting started, **RimWorld — MinifyEverything** delivers a clean, intuitive experience packed with everything you need — right out of the box. Join thousands of users who've already streamlined their RimWorld modding workflow. Download now and get started in minutes. 🚀

## 🚀 Features

| Feature | Description |
|---------|-------------|
| Universal Minify | Any building can be packed into a transportable item |
| Zero Material Loss | Uninstalled buildings retain their full resource value |
| Caravan Friendly | Pack your entire base for a colony relocation or caravan trip |
| Works with Mods | Automatically supports buildings added by other mods |
